这道题为什么要分 x ≤ 1 和 x > 1 两种情况讨论？直接代入不行吗？

因为 f 是分段定义的，内层 f(x) 落在哪一段，决定了外层该用哪个表达式。判定依据是内层结果是否 ≤ 1。

1先看内层：x ≤ 1 时 f(x)=x，此时 f(x) ≤ 1 仍成立，外层继续用第一段。
f[f(x)] = f(x) = x　(x ≤ 1)
2再看 x > 1：内层 f(x)=0，而 0 ≤ 1，外层应改用第一段。
f[f(x)] = f(0) = 0　(x > 1)

所以答案是分段函数，不能整体直接代入 —— 关键在于内层输出落在哪一段由外层判定。
