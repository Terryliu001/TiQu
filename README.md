# 题取 · PDF 题目助手

把一份 PDF 试卷拖进浏览器，自动框出每一道题。选中任意一题，题面会以**截图**形式交给你的 AI —— 公式和图形不会被文字转写弄乱。

纯前端、免安装、零后端。文件不上传，密钥只存在本机。

## 能做什么

- **自动框题**：文字版 PDF 走文本层切题；扫描件（没有文字层）走像素版面分析。两份真扫描卷实测 33/33 道题全中。
- **手动校准**：拖动、拖角缩放、空白画新框、并入上一题、拆分、改题号、删除，全部可撤销。
- **问 AI**：题面 2× 截图 + 可选文字，流式回答，支持多轮追问、Markdown 与 LaTeX 排版、思考过程折叠。
- **自带密钥（BYOK）**：预置 DeepSeek / 通义千问 / 智谱 / Kimi / 硅基流动 / OpenAI，也能填任意 OpenAI 兼容地址。
- **知识树（1.1）**：内置 15 章 / 84 个「数学分析」词条的关系图谱，Obsidian 风格拖拽缩放，悬停预览、点击细读、新建词条与互相关联，右栏可就词条追问 AI。
- **题库**：把历年《工科数学分析》真题按专题装订成 6 册、42 道题；书架最左是「题册」——15 份预置 PDF 原卷，一键载入工作台。每题带考点、来源与参考答案，公式实时渲染。
- **本地留存**：切题结果、手改记录、每题对话、知识树改动都存在 IndexedDB，重开即恢复。

不做：手写、答题卡、判题、学习记录、错题本。

## 快速开始

```bash
npm install        # 国内中文路径如遇 postinstall 报错，加 --ignore-scripts
```

## 知识树（v1.1 新增）

顶部导航切到「知识树」，是一张 Obsidian 风格的关系图谱：

- **数据**：15 章、84 个「数学分析」词条（从实数系到傅里叶级数），每章一个主题色；正文是 Markdown + LaTeX，公式由 KaTeX 渲染。
- **交互**：滚轮缩放、拖空白平移、拖节点移动；悬停节点在左栏预览，点击固定查看；可新建词条、编辑、删除、增删关联。
- **AI**：右栏以当前词条正文（含公式）为上下文继续追问，对话按词条保存。
- **持久化**：内置词条只读，你的新建/修改/关联写在 IndexedDB 覆盖层，刷新不丢、种子升级不冲突。
- 词条全文另附一份：[`宣传呈现/数学分析知识词条.md`](../宣传呈现/数学分析知识词条.md)。

## 接上你的 AI

右上角齿轮 → 选一家 → 填 Key → 「测试连接」。

- 题面截图需要**视觉模型**（`qwen-vl-max`、`glm-4v-plus`、`gpt-4o-mini` 等）。选到纯文本模型（如 `deepseek-chat`）时界面会明说"只发文字"，不会假装图发出去了。
- 密钥写在浏览器 IndexedDB 里，不经过任何服务器。清站点数据会丢，换浏览器要重填。

### 浏览器直连被拦（CORS）

少数厂商不允许浏览器直接调用。遇到"无法连接该服务"且确认网络正常时，起一个本地转发：

```bash
TARGET=https://api.deepseek.com/v1 node tools/proxy.mjs
# 然后把设置里的接口地址改成 http://127.0.0.1:8787/v1
```

### 切题怎么做的

```
PDF ─┬─ 有文本层 → 片段 → 聚行 → 分栏 → 题号 → 层级 → 区间切分
     └─ 无文本层 → 灰度像素 → 行投影 → 字高中位数 → 行首连通域字形分类
                              → 挂"伪题号" → 复用同一套切分
```

三条不能改的纪律（都是真卷踩出来的）：

1. **先分栏再聚行**。反了会把双栏页拼成横跨整页的一行。
2. **切题输入是"行"不是"片段"**。PDF 会把 `12.` 拆成 `1`/`2`/`.`。
3. **字号取中位数/下四分位**。多行公式会被报成一个超高对象，均值会把整页阈值带偏。

回归基线（`npm test`）：`eval-single-column` 11 / `eval-double-column` 9 / `eval-paren-sub` 20 / `eval-example-crosspage` 38 / `math-midterm` 18，全部精确命中。

## 已知限制

- 扫描件靠版面猜题号，认不出具体数字（题号由顺序补），选项行偶有漏网。
- PDF 文本层的公式碎片顺序可能是乱的（这是 PDF 本身的缺陷），所以题面截图才是权威输入；公式密集的题不会附文字。
- 单页视图，不做连续滚动。
- 大文件（100 页以上扫描件）切题会慢，有进度条但不可中断。

## 隐私

所有处理都在浏览器里。PDF、切题结果、对话、API Key 都只存本机 IndexedDB。没有任何遥测、没有后端。
